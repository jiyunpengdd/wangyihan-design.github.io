01设计原则

五条贯穿全站的视觉原则，每条都附实现依据。

一线到底：全部图标 1px 线性描边

所有图标共用 .svgic：16×16 视窗、fill:none、stroke:currentColor、stroke-width:1、圆头圆角。图标颜色永远继承文字色，不单独上色。

.svgic{width:16px;height:16px;fill:none;stroke:currentColor;stroke-width:1}
一个主色，其余靠深浅灰

强调色只有 --primary #2f6bff 与其浅底 --primary-soft #eaf1ff；语义色仅用于状态（成功/警告/危险）。界面层级由 --ink / --ink2 / --ink3 三级灰与 --line / --line2 两级描边构成。

--ink:#1f2329; --ink2:#4e5563; --ink3:#9aa1ad; --line:#ececf0
卡片 = 1px 边 + 大圆角 + 极小阴影

卡片不做重投影：1px 描边定义边界，14px 圆角柔化，阴影只有 3% 透明度的一层，靠留白而不是靠投影分层。

.card{border:1px solid var(--line);border-radius:var(--r);box-shadow:0 1px 4px rgba(31,35,41,.03)}
先给结论，再给依据

答复气泡里所有内容都遵循「小标题 → 表格/清单 → 提示条 → 快捷按钮 → 执行详情」的顺序；执行详情默认折叠（.trace 需 .open 才展开），把过程收在结论之后。

trace / plan / confirm 三类内容卡片的排列顺序
同一元素只允许一个选中态

导航按当前视图判断高亮，任务条按当前会话判断，二者互斥：进入功能页时任务条不再高亮。

一个视图内 .on 只出现在导航或任务条其中一处

11使用约定

几条硬约定，避免后续迭代跑偏。

类别约定
颜色只允许使用 --primary / --ink* / --line* / --ok / --warn / --danger 与 soft 系列。新增语义色必须先加变量，再在文档登记。
圆角按 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12 / 14 / 16 / 18 / 20 阶梯取值，不要出现 11px、13px 这类中间值。
字号正文 14，界面文字 13.5，说明 12.5，辅助 11.5，最小 10.5。小于 10.5 只允许出现在密集表格里。
图标只用图标库里的图标；尺寸 12 / 13 / 15 / 16 四档；不要改 stroke-width（全局 1，箭头按钮例外 1.5）。
选中态一个视图内只允许一个 .on；导航与任务条互斥，切换视图时先更新视图状态再重绘。
卡片统一 .card（14 圆角 / 18 20 内距 / 3% 阴影）。表格类内容加 .tblcard 让表格贴边。
浮层菜单/抽屉/提示层叠顺序固定：遮罩 40 → 抽屉 50 → 输入浮层 60 → Toast 99 → 任务菜单 130。
写操作一律「确认卡 → 执行 → Toast + 撤销条」三段式，绝不静默改数据。
